## Connecting the project choices

Use the LC-3 calculator after subroutines and stacks. Use the C calculator after strings and functions, with the stack concepts as useful background. The older borrowing-system project belongs after structures and linked lists. The Caesar-cipher projects provide an alternative path through character processing in both languages.

Original solutions are linked in expandable sections on the associated chapter pages. Attempt the problems first. The archive does not certify every answer or implementation, and it deliberately does not include student submissions.
