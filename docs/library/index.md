## Choose a way through

- **Following the course:** work down the reading map, completing the linked exercises as you go.
- **Looking up a concept:** use the chapter descriptions or site search. Search covers these guide pages, not the full text inside PDF/PPTX downloads.
- **Practicing:** use the [assignment index](assignments.md). Original solutions appear in expandable sections after the relevant exercises.

## About this first collection

There are **73 downloadable teaching files**: 11 Fall25 chapter PDFs, earlier lectures, assignments, original solutions and selected teaching examples. Files show their format and size before you open them. Large PDFs can take time to load.

Chapter reading lists also include **Download PDF** links. If your browser shows a blank PDF viewer, save the file and open it in a PDF reader.

The source files are preserved as historical teaching material. Dates, classroom logistics and submission portals inside them are not current requirements. Check [known corrections](errata.md) before using the affected readings, and use [sources and coverage](sources.md) to see what has been included or remains to be reconciled.
