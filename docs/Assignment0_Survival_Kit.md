## Overview  
In this assignment, you will design and assemble your own **LC-3 Survival Kit**—a personalized set of study and problem-solving tools to help you master the LC-3 assembly language and computer architecture concepts. This kit should be practical, easy to use, and tailored for students like you, who will rely on it throughout the course.  

You will use the provided reference documents (ISA appendix, LC-3 manual, and lab examples) as your **core material**, but the final design and layout of the kit is up to you. Creativity and accessibility will be rewarded!  

---

## Required Contents  

1. **Instruction Reference Cards**  
   - Create **15 double-sided cards**, one for each LC-3 instruction.  
   - **Front:** concise definition, opcode structure, and effects.  
   - **Back:** one worked example in LC-3 assembly.  

2. **Instruction Structure Table**  
   - A compact, one-page table listing the **binary format** of all LC-3 instructions, with fields labeled (DR, SR1, imm5, etc.).  

3. **Conversion Table**  
   - Quick reference for converting between **binary, decimal, and hexadecimal**.  
   - Include **ASCII encodings** for characters to aid in I/O instructions (e.g., PUTS, GETC).  

4. **Memory System Map**  
   - Visual diagram of the LC-3 memory system (Trap Vector Table, Interrupt Vector Table, OS/Supervisor stack, User program space, Device registers).  
   - Include registers (R0–R7, PC, IR, PSR, Condition Codes).  

5. **Main Working Sheet** (template provided)  
   - Four columns: **Address | Hex (4-digit) | Binary (16-bit) | LC-3 Assembly**.  
   - This will be your **active coding scratchpad**.  

6. **Register State Tracker**  
   - Scratch paper template to track **register changes step-by-step** during program execution.

## Deliverables
