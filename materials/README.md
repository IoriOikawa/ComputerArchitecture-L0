## 组织原则

用户选择以 Fall25 的章节分组为主线，把 `Past Material - 24` 中补充性的讲义和作业接入同一学习顺序。网页沿用原站英文内容，文件来源和维护说明保留在仓库中。

| 位置 | Fall25 主线 | 旧资料承担的角色 |
| --- | --- | --- |
| Chapter 0–2 | 课程动机、历史、性能衡量 | 保留 Fall25 顺序 |
| Chapter 2 与 3 之间 | 二进制概念进入 LC-3 | Representation 1–3、Digital Logic 1–2，配 HW1–2 和 InClass 1–2 |
| Chapter 3 | LC-3 组成与 ISA | von Neumann Model、指令和寻址详解，配 HW3 |

| Chapter 7 | 高级语言和 C 构建过程 | Linux、未使用目录中的 C 基础/控制流/函数/调试，以及 C warm-up |
| Chapter 8 | C、间接访问、指针和数组 | Pointers 1–2、HW6、指针练习 |
| Chapter 8 后 | C 拓展 | I/O、struct、链表、HW7、借阅系统项目和递归题源文件 |

## 交付与溯源

- `catalog.json`：73 份站内下载文件，包含源文件相对路径、目标路径、大小、页数、角色和 SHA-256。
- `source-inventory.json`：170 条教学文件/来源版本记录，覆盖导入、可编辑原稿、精确重复、替代版本和待处理文件。
- 站内资源约 107.2 MiB，单个最大文件约 31.1 MiB。没有把所有 Keynote 原稿复制到 Git。
- 章节 PDF 和旧讲义的文字用于主题映射；关键勘误页另行渲染目视核对。没有宣称完整校对所有图形、公式或示例程序。
- 来源路径相对于本地课程目录 `CS260 - Compter Architecture`，不依赖某位贡献者的绝对主目录。
- 不把学生姓名、成绩、提交文件清单放入这两个维护清单。考试、照片和安装程序也不在本次讲义/作业导入范围。

## 版本取舍

1. **Fall25 章节版为阅读主版本。** 导入 Chapter 0–8 的九份 PDF，加 Chapter 5+ 和 Chapter 5 的 62 页替代版本，共 11 份。
2. **Chapter 5 的“拷貝”不是重复。** 36 页主版本覆盖循环与冒险入门；62 页版本含更完整的字符计数和流水线冒险内容；25 页 Chapter 5+ 连接机器码与汇编。三个入口均保留。
3. **精确相同的文件按哈希识别。** Lecture 3 的 KEY/PPTX 拷贝、Lecture 27 的 KEY 拷贝、Lecture 7 与 Lecture 8 的 KEY 内容分别相同；未改动源目录。
4. **Assignment 0 选择可读 PDF。** `Assignment0.md` 实为含 RTF 控制内容的文件，`Assignment0.pdf` 又把这段内容排进了 PDF。站内使用 `Assignment0_Survival_Kit.pdf`，其余有效替代导出保留清单，不把不同哈希当作相同版本。
5. **旧资料以 PDF 为阅读版本。** 已存在 PDF 的 PPTX 对应稿保留来源记录；`didn_t use` 下只有 PPTX 的四份 C 讲义提供源文件下载，未自动转换。
6. **HW8 只有 LaTeX 源文件。** 内容为递归计数和回文题，内部标题写 HW6，样例还有重复左花括号。作为草稿素材提供，不伪装成完成的 PDF 练习。
7. **参考资料和题目区分。** 教材节选及外部 ISA/数据通路讲义没有被冒充为作者自己的章节。
8. **原答案不等于经过新验证的答案。** 旧解答放在对应章节的折叠区；程序没有全部重新编译或运行。

## 更新方式

新增或替换下载文件时，更新 `catalog.json` 的哈希、大小和来源，并更新章节介绍与 `sources.md` 的下载索引。若修改历史文件，不应继续沿用“原始副本”的记录，应保留原来源并注明修订。

维护清单不参与 MkDocs 发布；`docs/superpowers/` 计划目录通过配置明确排除。面向读者的资料说明位于 `docs/library/sources.md`。
